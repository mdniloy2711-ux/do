## 1. Put the code on GitHub

The repo name matters: this project is configured for **`nirob-portfolio`**.

### Option A — upload in the browser (no commands)
1. Go to https://github.com/new
2. Repository name: **`nirob-portfolio`** → Public → **Create repository**
3. On the new repo page click **uploading an existing file**
4. Drag in **everything** from this folder **except** `node_modules` and `dist`
   (the `.github` folder must be included — it holds the deploy workflow; `index.html`, `package.json`,
   `vite.config.ts`, `src/`, `public/` too)
5. Commit changes.

### Option B — with Git
```bash
git init
git add .
git commit -m "Nirob portfolio"
git branch -M main
git remote add origin https://github.com/Nirob-420/nirob-portfolio.git
git push -u origin main
```

> If you use a different repository name, change `BASE` in `vite.config.ts`
> to `"/your-repo-name/"` (keep both slashes). For `Nirob-420.github.io`, use `"/"`.

## 2. Turn on GitHub Pages (one time)

1. Repo → **Settings** → **Pages**
2. Under **Build and deployment → Source**, choose **GitHub Actions**
3. Open the **Actions** tab → the **Deploy to GitHub Pages** workflow runs automatically
   (it also runs on every push to `main`)
4. Wait for the green check, then your site is live at:

**https://nirob-420.github.io/nirob-portfolio/**

If the Actions tab shows no workflow, check that `.github/workflows/deploy.yml` was uploaded.

### Cadet photo
1. Save your parade photo as **`public/nirob/bncc.jpg`**
2. In `src/data.ts` set **`cadetPhoto: true`**
3. Push. The cadet section will show the photo inside its scroll reveal.

Until then the section shows a designed cadet record and makes no failed request.

## 4. Local development

Node.js 20+ required.

```bash
npm install
npm run dev        # http://localhost:5173/nirob-portfolio/
npm run build      # production build → dist/
npm run preview    # test the production build
```

## 6. Notes

- Builds are single-file (`vite-plugin-singlefile`), so `dist/index.html` contains the app; photos stay in `dist/nirob/`.
- `dist/404.html` is generated by the workflow as a routing fallback.
- `node_modules/` and `dist/` are ignored by `.gitignore` and must not be uploaded.
- Keyboard: **⌘K / Ctrl+K** search, **Esc** closes overlays, arrow keys browse projects.
